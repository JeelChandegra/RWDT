# Flower Assignment

This project contains two simple HTML and CSS pages that display a sunflower and a rose.

## How to View

To view the pages, simply open the `Html_assignment/flower.html` and `Html_assignment/rose.html` files in your web browser.

## Project Structure

* `Html_assignment/`: This directory contains all the files for the project.
  * `flower.html`: The HTML file for the sunflower page.
  * `flower.css`: The CSS file for the sunflower page.
  * `rose.html`: The HTML file for the rose page.
  * `rose.css`: The CSS file for the rose page.
